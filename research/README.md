## 用法约定

- **这里只攒、不写观点**。料升级成某期主轴 → 进 `issues/00X-{slug}/`,观点在 draft.md 里长。
- **官方源失效防护**:重要一手页面除了记 URL,该截图/存 PDF 的进 [refs/citations/](../refs/citations/)。
- **时效衰减**:landscape 快照会过期,标了建库日期;超过 2-3 个月再用要复核数字。
- **跟 inbox 的分工**:零散一句话灵感丢 [inbox.md](../inbox.md);成体系的源目录 / 主题地图留这里。
