多模态大模型架构 · 三代演进
GENERATION 1
第一代
图片翻译成文字
图像
→
图像识别
↓
文字描述
↓
LLM
视觉模型先把图描述成一段话，再把文字喂给 LLM。信息严重损失，盲人摸象。
代表 · 早期图文模型 / 2022 前
GENERATION 2
第二代
装上视觉义眼
图像
→
CLIP 编码器
↓
高维向量
↓
LLM
视觉编码器把图变成向量直接注入 LLM。但编码器和 LLM 分开训练，配合不默契，睁眼瞎。
代表 · LLaVA / BLIP-2 / Flamingo
GENERATION 2+
第二代+
联合训练改进
图像
→
CLIP 编码器
↓
LLM
一起训练
编码器和 LLM 一起继续训练，配合默契很多。但文字仍是绝对主角，思考的语言只有文字。
代表 · Qwen2.5-VL / GLM-V / Claude / MiniCPM-V
GENERATION 3 · NATIVE
第三代真原生
把图像也变成 token
文字 token
图像 token
音频 token
↓
统一 Transformer
从训练第一天就联合预训练
所有模态切成 token，从输入第一层进同一个模型。文字不再是特权语言，所有模态平等参与预训练。
代表 · Chameleon / Janus-Pro / Qwen2.5-Omni / Emu3 · GPT-4o / Gemini（声称）
数据来源 · Chameleon / Gemini / GPT-4o / LLaVA 论文与官方博客
