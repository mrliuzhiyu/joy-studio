怎么从外部网址抓图

  1. HTML 页面里的图（官方博客 / GitHub README）：浏览器打开页面 → 右键图片 → 图片另存为
  2. Chrome 抓不到原图（懒加载或动画）：F12 打开开发者工具 → Network → Img 标签 → 刷新页面 → 找到图片 URL → 右键 Open in new tab → 另存为
  3. arXiv 论文里的图：下载 PDF → 用截图工具截图（推荐 ShareX / Snipping Tool）
  4. 动态加载的图：F12 → Elements → 找到 <img> 标签 → 复制 src URL → 浏览器粘贴打开

版权注意

  • arXiv 论文里的架构图：学术使用可以引用，记得标来源
  • GitHub 仓库 README 里的图：开源项目自己提供，可使用，标来源
  • 官方博客里的图：属于厂商版权，引用使用通常 OK 但要标明来源
  • 所有卡片底部都有出处链接，本身就是合规引用的形式

整体素材工作流

  1. 浏览器右键下载 / 截图工具截图，保存图片到本地
  2. 本工具：拖图 + 填字 → 下载 self-contained HTML 卡片
  3. 浏览器打开卡片 → 截屏（推荐高分辨率屏幕）→ 保存 PNG
  4. 上传 PNG 到公众号素材库 → 拿到素材库 URL
  5. 在 wechat.html 里把图片占位符替换成素材库 URL
