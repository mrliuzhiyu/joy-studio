## 一、参考资料分组（反馈 A 复核）

### 现状评估

当前 4 分组：**官方文档 / 学术论文 / GitHub 开源 / 第三方分析 / 接续**——完全对齐 design.md §11.A 的「不超过 4 组」+「按引用类型」原则。比「一手 / 二手」自然得多，**改对了**。

### 微调建议（不必硬改，按你判断）

**1. 「官方文档」更名为「官方资料」**（design.md §11.A 用的是「官方资料」原词，TechCrunch 报道目前归在「第三方分析」下，但若改成「官方资料」分组里，TechCrunch 这种新闻报道就更显得不属于该组——保持「官方文档」反而精确。建议保留「官方文档」、不动）。

**2. TechCrunch 的归属**——现在归「第三方分析」OK。但 TechCrunch 是「新闻报道」、不是「分析」。如果你要更精细，可以改成「第三方报道与分析」或者把 TechCrunch 单独提到第一项。**当前归类没硬错、可保留**。

**3. 学术论文组**——MemGPT / Mem0 / LongMemEval / LoCoMo 4 篇排列合理，但 LoCoMo 严格说不是 arxiv 论文（是 Snap Research 自家页面+论文）。当前文件名「LoCoMo 基准 · Snap Research」表述准确，没问题。

**4. 第三方分析组里 HotpotQA 的位置**——HotpotQA 是 leaderboard / benchmark，不是「第三方分析」。可以单独算「benchmark」或归到「学术论文」组（HotpotQA 有 EMNLP 2018 论文）。**建议**：移到「学术论文」组末尾、改名「HotpotQA 多跳问答 leaderboard · EMNLP 2018」。这样「第三方分析」组就是清一色的 narrative 类来源，更整齐。

**5. 接续组**——只有 1 条且 URL 是「待 004 期发布后回填」。等 004 期出公号链接后回填，结构 OK。

### 总评

**4 分组 + 接续比「一手 / 二手」清晰多了**。HotpotQA 挪到学术组是唯一可优化点，其它保留。

### 2.3 可保留的破折号原则

中文里破折号的合理用法（这 30% 应该留）——

1. **真正的强转折 / 反转**：「不是 A——是 B」，前后是对立判断。例：行 90 「不是设计模型——是设计这层壳里的笔记本机制」、行 188 「Letta 公开宣布——它的新一代记忆系统、不要这个能力」、行 261 「不是去掉了图、是把图退到了信号层」。这种破折号是判决式语气、不能改成冒号或句号。
2. **列举式 + 标签**：图书馆类比那三段（行 99-103），「读完——是内存」「再借——是缓存」式的标识用法。改了反而失去节奏。
3. **真正的补充说明、且括号会臃肿**：例如 「Letta 这家公司——也就是 MemGPT 论文一作创办的那家——」，这种嵌入式补充在长名词后用括号会撑断节奏。但本文里此用法极少（多数双破折号建议改成括号）。
4. **引文段前的过渡**（一句话引出后面整段引文）：行 41/181/222/324 这种 `...这么一句话——`+ 独立引文段、保留破折号是合理的（虽然冒号也行）。

不该用破折号的所有场景——

- 引出译文（用「：」）
- 引出定义 / 机制描述（用「：」）
- 引出列举（用「：」）
- 自问自答（直接陈述句、不要先问再答）
- 双破折号包补充（用括号）
- 「X——是 Y」的解释式（拆成两句）
