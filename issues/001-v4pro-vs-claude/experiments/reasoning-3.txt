- viewBox="0 0 300 300"

- 周长 = 2 * π * 120 ≈ 753.98
- 使用stroke-dasharray: 753.98; stroke-dashoffset: 0(满)到753.98(空)

进度 = 已过时间 / 总时间
dashoffset = 周长 * (1 - 进度) = 周长 * (剩余时间/总时间)

即：dashoffset = circumference * (remainingSeconds / totalSeconds)

这样当remaining=total时，dashoffset=circumference（环形完全未填充，即空的）
当remaining=0时，dashoffset=0（环形完全填充）

等等，让我确认一下。在SVG中，stroke-dashoffset的默认值是0，此时虚线从起点开始。如果dasharray=周长，dashoffset=0，则整个圆被描边。如果dashoffset=周长，则描边完全偏移出去，圆环是空的。

所以：
- 满进度（时间用完）：dashoffset = 0
- 空进度（时间刚开始）：dashoffset = 周长

剩余时间比例 = remainingSeconds / totalSeconds
dashoffset = circumference * (remainingSeconds / totalSeconds)

是的，这样当剩余时间为总时间时，dashoffset=周长（环看起来是空的/刚开始），当剩余时间为0时，dashoffset=0（环完全填充）。

但实际上我们想要显示"已过去的时间"作为填充进度。所以：
- 刚开始：剩余=total，dashoffset=周长，环是空的 ✓
- 时间过半：剩余=total/2，dashoffset=周长/2，环填充一半 ✓
- 时间到：剩余=0，dashoffset=0，环完全填充 ✓

还有一个事情：关于audio/sound。用户没有要求声音提示，所以不添加。但阶段切换时的视觉提示很重要。我会让阶段标签在切换时有一个短暂的缩放或颜色脉冲动画。

对于环形进度条在阶段切换时的处理：切换到新阶段后，进度条应该快速重置为满（dashoffset = circumference），然后随着新阶段的进行逐渐减少。这个重置可以配合transition，看起来进度条"回弹"到满。

如果使用300ms的transition，进度条重置会有一个可见的动画（从0到满），这是可以接受的。但如果阶段切换时进度条在0的位置（时间耗尽），它会在300ms内回到满的位置，这是合理的视觉效果。

好的。现在对于阶段切换时，我先设置dashoffset为新值，transition会自然处理动画。

还有一件事很重要：当用户点击"跳过"时，如果计时器正在运行，需要先清除定时器，切换阶段，然后自动开始新阶段。如果计时器已暂停，切换阶段后也自动开始。

当用户点击"重置"时，清除定时器（如果正在运行），将剩余时间重置为当前阶段的初始值，更新显示。
